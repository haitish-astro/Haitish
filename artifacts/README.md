# Portfolio Artifacts

Use this folder for source materials that should appear on the portfolio later.

## Folder Map

- `photos/` - profile photos, project images, lab photos, screenshots, renders, and website visuals.
- `pdfs/` - resume PDFs, published papers, certificates, reports, and export-ready documents.
- `documents/` - editable drafts, notes, Word documents, text outlines, and supporting files.
- `projects/` - project-specific folders for artifacts that belong together.
- `publications/` - publication PDFs, abstracts, posters, presentation decks, and citation notes.

## Current Live Files

- `photos/profile-photo.png` - profile photo used on the home and about pages.
- `photos/hero-aerospace.png` - aerospace hero visual used as the page background.
- `pdfs/haitish-gandhi-resume.pdf` - resume PDF linked from the site.

When adding new material, keep filenames lowercase and descriptive, for example
`hydroquad-cfd-contour.png` or `nasa-lspace-final-proposal.pdf`.
