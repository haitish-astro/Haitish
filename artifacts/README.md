# Portfolio Artifacts

Use this folder for source materials that should appear on the portfolio later.

## Folder Map

- `photos/` - profile photos, project images, lab photos, screenshots, renders, and website visuals.
- `pdfs/` - public papers, certificates, reports, and export-ready documents.
- `documents/` - editable drafts, notes, Word documents, text outlines, and supporting files.
- `projects/` - project-specific folders for artifacts that belong together.
- `publications/` - publication PDFs, abstracts, posters, presentation decks, and citation notes.

## Project Folders

- `projects/hydroquad/` - HyDroQuad concepts, renders, analysis, and project documents.
- `projects/nasa-lspace/` - NASA L'SPACE proposal artifacts, heat shield concepts, and review materials.
- `projects/suparna-bio-inspired-uavs/` - SUPARNA wing morphing design research, figures, drafts, and prototypes.
- `projects/laser-propulsion/` - laser propulsion research notes, plots, presentations, and supporting files.
- `projects/paver-canopy/` - Eagle Flight Research Center PAVER fairing/canopy design artifacts.
- `projects/launch-vehicle/` - EGR101 launch vehicle files, drawings, calculations, and reports.
- `projects/alarm-clock-design/` - Graphical Communications alarm clock CAD, drawings, and design notes.

## Current Live Files

- `photos/profile-photo.webp` (1148 px) and `photos/profile-photo-640.webp` - profile photo on the home, professional, and about pages.
- `photos/hero-aerospace.webp` (1774 px) and `photos/hero-aerospace-1100.webp` - aerospace hero visual behind the home and professional heroes.

Images are WebP for size (the original PNGs were roughly 1.8 MB each). When adding
new material, keep filenames lowercase and descriptive, for example
`hydroquad-cfd-contour.webp` or `nasa-lspace-final-proposal.pdf`, and give every
`<img>` explicit `width`/`height` so the layout does not jump while it loads.

Avoid committing private career documents, direct personal contact details,
transcripts, IDs, private reports, or proprietary files unless they are meant to
be public.
