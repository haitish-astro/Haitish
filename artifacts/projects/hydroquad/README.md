The case study distinguishes modeled performance from initial flight observations.
Mass and model outputs are from Tables 6-7; the 6:02 duration is from the flight
test discussion on page 17. The roughly 29-second / 7% comparison is calculated
from 6.51 minutes predicted and 362 seconds observed, relative to the prediction.

The manuscript has differing CFD thrust values and motor KV selections across
sections. The page therefore avoids presenting a single CFD thrust value or KV
rating as a verified result. The wake plot's color legend is Particle ID, not
velocity. Earth-based flight testing is not evidence of planetary flight or
autonomous ground-to-air transitions.

The full manuscript and the residential-background field photos are not included
in the public repository. The publication link reuses the DOI already listed on
the professional page.
