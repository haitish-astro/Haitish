# Haitish Gandhi Portfolio Prototype

Static multi-page aerospace engineering portfolio prototype for GitHub Pages.

## Pages

- `index.html` - home page and portfolio introduction
- `about.html` - biography and capability summary
- `projects.html` - aerospace project placeholders
- `contact.html` - contact and resume placeholder

## Publishing With GitHub Pages

1. Commit and push these files to `main`.
2. In GitHub, open repository settings, then Pages.
3. Set Source to `Deploy from a branch`.
4. Select branch `main` and folder `/root`.
5. Save and wait for GitHub Pages to publish.

Expected public URL:

```text
https://haitish-astro.github.io/Haitish/
```

No build step is required.
